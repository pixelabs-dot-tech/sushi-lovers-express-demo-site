# Sushi Lover's Express: website concept (built site)

This repository holds only the **built** client-demo website: `site-dist.zip` is
the static output served at https://indigo-hummingbird-402431.hostingersite.com.

It is a concept prepared for Sushi Lover's Express and is not the restaurant's
official website. The source lives in a separate private repository; this repo
is updated automatically by its `tools/publish-branches.sh` script. Please don't
edit it by hand.
